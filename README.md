# 👋 Hello, I'm Gustavo Miguel

I'm a **Senior Full Stack Software Engineer** with 6+ years of experience building and evolving SaaS products.

Throughout my career, I've worked across both **frontend and backend development**, helping modernize legacy applications, build scalable solutions, and develop features used by enterprise customers.
